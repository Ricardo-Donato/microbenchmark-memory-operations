# Microbenchmark de Operações em Memória (PBL)
O presente repositório é destino ao trabalho em que os integrantes necessitam estabelecer um cenário equivalente ao explanado na situação-problema para apresentar qual sistema operacional apresenta melhor desempenho nas operações de memória e quais evidências sustentam essa conclusão.

# Situação-problema
Uma empresa responsável pela integração de serviços digitais em cidades inteligentes precisa comparar o tempo das operações de em Windows e Linux. Para isso, deverá realizar um experimento em condições equivalentes, armazenar e analisar as métricas coletadas e recomendar o sistema operacional com melhor desempenho nas condições avaliadas.
nas condições experimentais definidas, qual sistema operacional apresenta melhor desempenho nas operações de memória e quais evidências sustentam essa conclusão?
